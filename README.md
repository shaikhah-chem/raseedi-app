# ✨ رصيدي الذهبي ✨
### «كل مبادرة... تصنع فرقًا»

نظام تحفيز ومتابعة للطالبات قائم على النقاط الذهبية. يعمل على الجوال والتابلت والكمبيوتر، ويحفظ كل البيانات في قاعدة بيانات حقيقية.

## 2) التشغيل لأول مرة — 15 دقيقة تقريبًا

### الخطوة 1: إنشاء قاعدة البيانات في Supabase (مجاني)
1. ادخلي إلى **https://supabase.com** وسجّلي حسابًا (يمكن بحساب GitHub أو Google).
2. اضغطي **New project**:
   - Name: `raseedi`
   - Database Password: اختاري كلمة قوية واحفظيها.
   - Region: الأقرب لك (مثل Frankfurt).
3. انتظري دقيقة حتى يجهز المشروع.

### الخطوة 2: إنشاء الجداول
1. من القائمة الجانبية افتحي **SQL Editor** ← **New query**.
2. افتحي ملف `supabase/01_schema.sql` وانسخي **كل** محتواه، والصقيه، ثم اضغطي **Run**.
   يجب أن تظهر رسالة **Success**.
3. (اختياري للتجربة) افتحي استعلامًا جديدًا والصقي `supabase/02_demo_data.sql` ثم **Run**.

### الخطوة 3: إعدادات الأمان (مرة واحدة)
في Supabase ← **Authentication**:
- **Sign In / Providers** ← أوقفي **Allow new users to sign up**.
  الحسابات تُنشأ من داخل الموقع فقط بواسطة المعلمة، فلا حاجة للتسجيل الذاتي.
- **Rate Limits** ← ارفعي «Sign-in / Sign-up requests» إلى **150** مثلًا.
  الحد الافتراضي قد لا يكفي عندما تدخل 30 طالبة في الوقت نفسه من شبكة المدرسة.

### الخطوة 4: ربط الموقع بقاعدة البيانات
1. في Supabase افتحي **Project Settings** ← **API** (أو **API Keys**).
2. انسخي:
   - **Project URL**، مثل `https://abcd1234.supabase.co`
   - **anon public key** (أو **Publishable key**)
3. افتحي الملف `site/config.js` بأي محرر نصوص (حتى Notepad) والصقي القيمتين:
```js
window.RASEEDI_CONFIG = {
  SUPABASE_URL: "https://abcd1234.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi....."
};
```
> ⚠️ لا تضعي أبدًا مفتاح **service_role** في الموقع. المفتاح العام (anon/publishable) آمن لأن كل الحماية مطبقة داخل قاعدة البيانات.

### الخطوة 5: نشر الموقع على الإنترنت
**الطريقة الأسهل — Netlify Drop (دقيقة واحدة):**
1. ادخلي إلى **https://app.netlify.com/drop**.
2. اسحبي مجلد `site` كاملًا وأفلتيه في الصفحة.
3. سيظهر رابط الموقع فورًا. يمكنكِ تغيير اسمه من **Site settings ← Change site name** (مثل `raseedi-gold.netlify.app`).
4. لتحديث الموقع لاحقًا: **Deploys** ← اسحبي المجلد مرة أخرى.

**أو GitHub Pages (مثل موقع «الكيمياء البسيطة»):**
1. أنشئي مستودعًا جديدًا، وارفعي **محتويات** مجلد `site` (وليس المجلد نفسه).
2. **Settings ← Pages ← Deploy from a branch ← main / root**.

**أو Vercel:** ارفعي مجلد `app` إلى GitHub، واستورديه في vercel.com، وأضيفي متغيري البيئة (القسم 6).

## 3) إنشاء حساب المعلمة

**إذا شغّلتِ البيانات التجريبية:** ادخلي بالحساب `teacher` / `Gold@2026`. بعد ذلك:
- غيّري كلمة المرور من **الإعدادات ← حسابي**.
- أو أضيفي حسابك الخاص من **الإعدادات ← المعلمات**.

**إذا لم تشغّليها (استخدام فعلي مباشر):**
1. افتحي رابط الموقع ← ستظهر رسالة «ابدئي الإعداد لأول مرة».
2. اكتبي اسمك واسم مستخدم إنجليزي (مثل `shaikha`) وكلمة مرور.
3. تُقفل هذه الشاشة تلقائيًا بعد إنشاء أول معلمة، ولا يستطيع أحد غيرك استخدامها.

## 4) إضافة الطالبات
1. **الإعدادات ← الفصول**: أضيفي فصولك (مثلًا: ثالث ثانوي — 3/1).
2. **الطالبات ← إضافة مجموعة**:
   - اختاري الفصل.
   - الصقي أسماء الطالبات (اسم في كل سطر، يمكنك نسخها من Excel أو نظام نور).
   - اضغطي **إضافة الطالبات**.
3. تظهر **بطاقات دخول** فيها اسم المستخدم (مثل `s3101`) وكلمة المرور، ويمكنك **طباعتها** أو **تصديرها Excel** لتوزيعها.
4. لإضافة طالبة واحدة: **إضافة طالبة**. ولنسيان كلمة المرور: زر 🔑 بجانب الطالبة.

## 5) البيانات التجريبية الجاهزة

| الحساب | اسم المستخدم | كلمة المرور |
|---|---|---|
| المعلمة | `teacher` | `Gold@2026` |
| الطالبة سارة | `sara` | `123456` |
| بقية الطالبات (9) | `s02` … `s10` | `123456` |

تشمل البيانات التجريبية:
- **الفصل 1/1**.
- **10 طالبات** بأرصدة ومستويات مختلفة.
- **درس المخاليط – الصف المقلوب** بمهامه الخمس، ومعه إنجازات جزئية لتري لوحة المتابعة.
- **5 مكافآت**، منها «+1 درجة في مهمة مؤهلة» بحد أعلى مرتين لكل طالبة.
- **سجلات نقاط** على مدى الأسابيع الماضية، ومثال خصم، ومثال استبدال.

للانتقال للاستخدام الحقيقي: **الإعدادات ← البيانات التجريبية ← حذف الطالبات التجريبيات**.

## 6) المفاتيح والمتغيرات المطلوبة

| المتغير | أين يوضع | من أين |
|---|---|---|
| `SUPABASE_URL` | `site/config.js` | Supabase ← Project Settings ← API ← Project URL |
| `SUPABASE_ANON_KEY` | `site/config.js` | Supabase ← API ← anon public / publishable key |

**لا يوجد أي مفتاح سري آخر مطلوب.**

## 7) استخدام الصف المقلوب غدًا (سيناريو جاهز)
1. **الصف المقلوب ← درس مقلوب من القالب** ← اختاري الفصل والموعد (مثلًا: السبت 10:00 م) ← **إنشاء الدرس**.
2. تُنشأ المهام الخمس وتصل الطالبات تنبيه «لديكِ مهمة جديدة»:
   1. الاختبار القبلي ⭐1
   2. مشاهدة فيديو الدرس ⭐1
   3. الإجابة عن أسئلة الفيديو ⭐2 (برفع صورة الإجابة)
   4. الدخول إلى ورقة ذكية ⭐1 (برمز QR)
   5. مهمة إثرائية اختيارية ⭐2
3. من **المهام ← تعديل** أضيفي رابط الفيديو أو الاختبار لكل مهمة، فيظهر للطالبة زر «فتح النشاط».
4. **ورقة ذكية / QR:** زر 🔳 QR يعرض رمز المهمة. يمكنك:
   - عرضه على الشاشة في الحصة لتمسحه الطالبات بالجوال.
   - أو وضع **رابط التسجيل** في نهاية الورقة الذكية، فتُسجَّل المهمة تلقائيًا عند فتحه.
5. تابعي من **الصف المقلوب**:
   - أشرطة إنجاز لكل مهمة.
   - أسماء من لم تُكمل.
   - زر **تذكير** يرسل تنبيهًا لهن.
   - جدول بكل الطالبات.

### قاعدة المسارعة العادلة
لا يعتمد النظام على «أول من تدخل». **كل طالبة تنجز المهمة قبل الموعد النهائي تحصل على النقاط كاملة.**
الإنجاز بعد الموعد يُسجَّل للمتابعة لكن **بدون نقاط**، ويمكنك منح نقاط يدوية إن رأيتِ ذلك.

### طرق التحقق من الإنجاز (لكل مهمة)

| الطريقة | كيف تعمل |
|---|---|
| ✅ تأكيد الطالبة | تضغط «أنجزتُ المهمة» وتُحتسب النقاط فورًا إن كان قبل الموعد. |
| 🔳 رمز المهمة / QR | تمسح الرمز أو تُدخله بعد تنفيذ النشاط، ويُسجَّل وقت التنفيذ. |
| 📎 رفع إثبات | صورة أو رابط أو وصف، ثم تعتمدينه أنتِ فتُضاف النقاط. |
| 👩‍🏫 رصد المعلمة | تحددين الطالبات من «متابعة الإنجاز». |

## 8) الأمان والخصوصية (مطبّق على الخادم)
- كل طالبة **ترى بياناتها فقط**. لا يوجد ترتيب ولا لوحة متصدرات في أي مكان.
- لا تستطيع الطالبة تعديل رصيدها. أي محاولة كتابة مباشرة ترفضها قاعدة البيانات (Row Level Security).
- كل إضافة أو خصم أو استبدال يتم عبر دوال على الخادم تتحقق من:
  - الصلاحية.
  - الموعد.
  - كفاية الرصيد.
  - الحد الأعلى للمكافأة.
  - منع التكرار.
- كل عملية تُسجَّل مع: الطالبة، والنوع، والنقاط، والسبب، والتاريخ والوقت، **والمعلمة المنفذة** (الإعدادات ← سجل العمليات).
- الطالبة لا تستطيع فتح صفحات المعلمة، وحتى لو حاولت فالخادم يرفض.
- رموز المهام مخفية عن الطالبات.

## 9) ملاحظات مهمة
- **الخطة المجانية في Supabase توقف المشروع مؤقتًا بعد 7 أيام بلا أي استخدام.** إن حدث ذلك ادخلي Supabase واضغطي **Restore**، ولن تضيع البيانات. الاستخدام المنتظم يمنع ذلك.
- **النسخ الاحتياطي:** صدّري التقارير دوريًا (التقارير ← تصدير Excel).
- الموقع يحتاج اتصالًا بالإنترنت.
